# To-Do List на TypeScript

Мой первый полноценный проект на TypeScript и чистом JavaScript (без фреймворков).

## 🚀 Функционал
- Добавление новых задач.
- Удаление задач (по одной).
- Отметка задач как выполненных (зачеркивание).
- Фильтрация задач (Все / Активные / Выполненные).
- Подсчет общего количества и количества активных задач.
- Очистка всех выполненных задач одной кнопкой.

## 🛠️ Технологии
- **TypeScript** (строгая типизация, DOM)
- **HTML5**
- **CSS3** (Flexbox, CSS-переменные, анимации)
